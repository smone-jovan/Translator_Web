# ADR-007: Bulk Title Translation & Dual-Title Schema

## Status
Accepted

## Date
2026-05-16

## Context
Navigating long novels (EPUB or Scraped) was difficult because chapter titles remained in the source language (e.g., Chinese or Japanese) even after content was translated. Users need a way to translate all titles in a novel permanently to facilitate easier navigation via the Reader's index view.

Requirements:
- Titles must be stored permanently in the database.
- Original titles must be preserved as a fallback.
- Translation should be bulk (efficient) rather than per-chapter on-demand, as titles are short and can be batched into a single LLM call.

## Decision
1.  **Database Schema Update**:
    -   Removed the single `title` column from the `chapters` table.
    -   Added `title_original` and `title_translated` columns to the `chapters` table.
2.  **API Integration**:
    -   Implemented `POST /api/threads/{id}/translate-titles` to trigger a batch translation of all chapters in a thread.
    -   Added `AIProvider.generate_batch()` to handle non-streaming, aggregated AI requests for efficiency.
3.  **UI Integration**:
    -   Added a "Translate Titles" button in the `ReaderPage` index view.
    -   Updated the UI to display `title_translated` if available, falling back to `title_original`.

## Alternatives Considered

### On-demand Title Translation
- **Pros**: Zero initial wait time.
- **Cons**: High latency when opening the index; redundant AI calls for every session; no permanent storage.
- **Rejected**: Persistent titles are better for user experience and navigation stability.

### Translating Title with Chapter Content
- **Pros**: Done automatically.
- **Cons**: Titles are needed *before* content translation for navigation; often requires context across multiple chapters.
- **Rejected**: Bulk translation allows the LLM to see multiple titles at once, improving consistency and reducing overhead.

## Consequences
-   Existing databases require a migration script (`scratch/migrate_db.py`) to add the new columns and move old `title` data to `title_original`.
-   Navigation is significantly improved as the Table of Contents (Index) is now readable in the target language.
-   Small token overhead for bulk translation calls.
