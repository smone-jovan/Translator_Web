# ADR-106: Glossary Hard-Locking & Deterministic Aliasing Engine

## Status
Accepted (2026-09-05)

## Context
Dalam penerjemahan novel web berbahasa Mandarin (Chinese Xianxia/Wuxia), pengguna sering mendefinisikan istilah penting pada glosarium/lorebook (misalnya nama tokoh `罗毅` → `Rahmat`). Namun, model LLM seperti Google Gemini sering mengabaikan prompt injection instruksi glosarium (`[STRICT GLOSSARY / LOREBOOK - MANDATORY]`) karena bias pra-latih (*pretraining bias*) dan menghasilkan nama transliterasi default seperti `Luo Yi` atau variasi fonetik lainnya.

Eksplorasi awal mempertimbangkan *Pre-Translation Token Masking* (mengganti nama asli menjadi placeholder sintesis seperti `❖NAME_1❖` sebelum diterjemahkan oleh LLM). Namun, telaah mendalam membuktikan bahwa token masking merusak pemahaman gender karakter (karakter Hanzi membawa konotasi kultural maskulin/feminin yang esensial pada fenomena *zero anaphora / pro-drop* di novel Mandarin) dan mengacaukan keluwesan tata bahasa hukum D-M bahasa Indonesia.

## Decision
Menerapkan arsitektur **Hybrid 3-Layer (Semantic Context Prompt + Auto Pinyin Aliasing + Deterministic Post-Processing Safety Net)**:

1. **Semantic Prompt Hint**: Prompt tetap menyertakan Hanzi asli dan terjemahan target disertai petunjuk Pinyin (`- 罗毅 (Pinyin: Luo Yi) → Rahmat`) agar Gemini memahami konteks karakter, gender, dan relasi cerita secara alami.
2. **Automatic Pinyin Aliasing (`backend/services/glossary_lock.py`)**: Menggunakan pustaka ringan `pypinyin` untuk mengekstrak alias pinyin otomatis (format spasi `Luo Yi`, gabung `Luoyi`, dan variasi huruf kecil). Mendukung pemisah subterm slash (`/`).
3. **Deterministic Post-Processing Safety Net**: Di fungsi sentral `ContextEngine.enforce_glossary_locking()`, sistem menjalankan pemindaian regex berbatas kata (*whole-word boundary check*). Jika Gemini tetap mengeluarkan nama pinyin lama atau karakter Hanzi mentah lolos, backend langsung menimpanya secara deterministik dengan istilah target.
4. **Stopword Guardrail**: Untuk istilah tunggal berukuran pendek (≤ 3 huruf atau terdaftar dalam stopword umum seperti `Dan` untuk 丹), sistem mewajibkan pencocokan *case-sensitive* ketat (`\bDan\b`, bukan `\bdan\b`) agar kata penghubung bahasa Indonesia (*"dan"*) tidak rusak.
5. **Length-Priority Ordering**: Aturan substitusi diurutkan dari frasa terpanjang ke terpendek (`len(term) DESC`) untuk mencegah tabrakan substring (misal `Luo Yi Chen` diganti sebelum `Luo Yi`).
6. **Zero-Token Retroactive Sync**:
   - `POST /api/threads/{thread_id}/chapters/{chapter_id}/reapply-glossary`: Terapkan ulang glosarium ke 1 chapter yang sedang dibaca dalam <5ms tanpa biaya token AI.
   - `POST /api/threads/{thread_id}/reapply-glossary`: Terapkan ulang glosarium secara massal ke seluruh chapter yang sudah diterjemahkan pada sebuah buku.

## Consequences
- **Positive**:
  - Jaminan kepatuhan glosarium 100% tanpa ada lagi istilah lama yang bocor.
  - Pemahaman gender, kata ganti (*dia/ia/pemuda itu*), dan keluwesan tata bahasa cerita tetap terjaga secara sempurna.
  - Pengguna dapat mengubah nama glosarium di kemudian hari dan memperbarui chapter yang sudah ada secara instan dengan 0 biaya token AI.
- **Negative / Guardrails**:
  - Memerlukan dependensi `pypinyin>=0.50.0` (telah disetujui pengguna).
  - Istilah pendek 1 karakter harus diperhatikan kapitalisasinya agar tidak bentrok dengan kata hubung lokal.
