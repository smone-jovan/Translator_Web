# ADR-008: Server-Side Configuration Sync & Multi-Device Access

## Status
Accepted

## Date
2026-05-16

## Context
Aplikasi ini awalnya menggunakan `localStorage` untuk menyimpan konfigurasi LM Studio (URL, Model, Bahasa). Masalah muncul ketika pengguna ingin mengakses aplikasi dari perangkat berbeda (misal: iPhone mengakses backend di Laptop):
1. Pengaturan di HP kosong dan harus diisi manual.
2. IP Laptop (Backend) sering berubah atau berbeda dari perspektif device lain (bukan `localhost`).
3. Kebijakan CORS memblokir akses dari IP non-localhost secara default.

## Decision
1. **Server-Side Settings**: Memindahkan sumber kebenaran (Source of Truth) pengaturan ke database SQLite (`global_settings` table).
2. **Dynamic API Discovery**: Frontend menggunakan `window.location.hostname` untuk menentukan `API_BASE` secara dinamis, sehingga akses via IP Lokal (`192.168.x.x`) langsung mengarah ke backend yang benar tanpa konfigurasi manual.
3. **Open CORS Policy**: Mengatur `allow_origins=["*"]` di FastAPI untuk mengizinkan akses dari perangkat mobile di jaringan lokal yang sama.
4. **Backend Fallback**: Background tasks di backend akan menggunakan pengaturan dari database jika request tidak menyertakan parameter spesifik.

## Alternatives Considered
- **Manual Input**: Merepotkan pengguna untuk mengetik URL panjang di layar HP yang kecil.
- **Environment Variables**: Kurang fleksibel karena user tidak bisa mengubah model atau bahasa secara realtime via UI.

## Consequences
- Pengguna hanya perlu mengatur LM Studio sekali di laptop, dan HP akan otomatis mengikutinya.
- Akses mobile menjadi "Zero Config" (selama di jaringan WiFi yang sama).
- Perlu dipastikan backend berjalan dengan `--host 0.0.0.0` agar bisa diakses device lain.
