# ADR-006: Implementation of Omni-Sepia Design System and Page Refactoring

## Status
Accepted

## Date
2026-05-16

## Context
The user has provided high-fidelity screenshots of a premium "Omni/Sepia" design. The existing UI is functional but basic. To provide a top-tier user experience consistent with the user's vision, the entire application needs to be refactored to align with this premium aesthetic.

## Decision
Adopt the "Omni-Sepia" design system across the entire application.

### Design Principles:
- **Color Palette**: Cream/Sepia background (`#F5F1E8`), soft brown text (`#4A3F35`), and high-contrast dark accents for primary actions.
- **Visual Style**: Large border radii (`rounded-xl` to `rounded-2xl`), subtle borders (`#E5E0D5`), and clean iconography using Lucide React.
- **Typography**: Standardize on **Atkinson Hyperlegible** for maximum readability in a literary context.
- **Page Structures**:
  - **Home**: Floating search/URL bar with integrated model/thread selection.
  - **Context**: Tabbed interface for Glossary and Rules with a data-rich terminology table.
  - **Settings**: Modal-based configuration with visual theme previews.
  - **Reader**: Distraction-free reading environment with floating toolbars and metadata badges (AI model, term modifications).

## Alternatives Considered
- **Maintaining the current UI**: Rejected because it doesn't meet the "premium" requirement and the user explicitly requested the new design.
- **Tailwind Default Theme**: Rejected in favor of a custom, highly curated color palette to match the "Omni" aesthetic.

## Consequences
- **Frontend Refactor**: Requires substantial changes to existing React components and global CSS.
- **Improved UX**: The interface will feel more like a professional reading tool rather than a generic translator.
- **Maintenance**: Custom design tokens will need to be strictly adhered to in future components.
