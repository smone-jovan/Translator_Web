# ADR-005: Automated Context Pipeline & Translation Persistence

## Status
Accepted

## Date
2026-05-16

## Context
Proses penerjemahan novel memerlukan konsistensi istilah (lore) yang sangat ketat. Sebelumnya, user harus secara manual mengekstrak istilah baru dan menyimpan hasil terjemahan. Hal ini menghambat alur kerja pembacaan yang cepat (binge-reading). Diperlukan sistem yang secara otomatis "belajar" dan menyimpan progres tanpa intervensi manual.

## Decision
Mengimplementasikan alur kerja otomatisasi di layer backend:

1. **Automated Glossary Extraction (AI-Driven)**:
   - Setiap respon terjemahan diwajibkan menyertakan bagian "Translator Notes:" jika ditemukan istilah baru (nama karakter, lokasi, item).
   - **Refinement**: Instruksi diperketat agar AI hanya menyertakan istilah yang *benar-benar muncul* di bab tersebut, bukan istilah contoh dari system prompt (Style Reference).
   - Backend memproses bagian ini secara asinkron setelah streaming selesai, melakukan parsing, dan menyimpannya ke database Lorebook secara otomatis.
   - Istilah baru ini langsung menjadi "Active Context" untuk bab berikutnya.

2. **Server-Side Translation Persistence**:
   - Menghilangkan ketergantungan pada tombol "Save" manual di frontend.
   - Endpoint `/api/translate/stream` kini menerima `chapter_id`.
   - Setelah streaming selesai, backend langsung menyimpan seluruh teks terjemahan ke record database bab yang bersangkutan.

3. **Service-Oriented "Deep" Architecture**:
   - Memindahkan logika pembentukan prompt ke `ContextEngine`.
   - Memindahkan logika koneksi ke `AIProvider`.
   - Hal ini memisahkan kekhawatiran (*Separation of Concerns*) dan memudahkan pemeliharaan prompt "Etik" terjemahan secara terpusat.

## Alternatives Considered

### Client-Side Auto-Save
- **Pros**: Lebih sedikit beban di backend.
- **Cons**: Tidak stabil jika tab browser ditutup atau koneksi internet terputus di tengah proses simpan. Backend auto-save jauh lebih handal karena terjadi di sisi server.

### Manual Glossary Management Only
- **Pros**: Data lebih bersih (tidak ada sampah AI).
- **Cons**: Sangat melelahkan untuk user. Keputusan diambil untuk memprioritaskan kecepatan alur kerja dengan asumsi user bisa melakukan pembersihan (edit/delete) di halaman Glossary jika AI salah deteksi.

## Consequences
- **User Experience**: User bisa membaca terus-menerus tanpa perlu klik tombol teknis (Save/Extract).
- **Consistency**: Lore novel tetap terjaga meskipun model AI berganti-ganti, karena database glossary terus diperbarui secara otomatis.
- **Data Integrity**: Terjemahan tersimpan secara otomatis, mengurangi risiko kehilangan progres akibat crash pada browser.
